# Pre-generated Servo properties

These files are the deterministic output of Stylo's Servo property generator at upstream
commit `f6d1d525db9a7fb1aa0842926458e63faa4f44c7`:

- `properties.rs`
- `css-properties.html`
- `css-properties.json`

They are committed so normal Servo builds need only Rust and Cargo. Do not edit them by hand.
When changing Stylo's property definitions or templates, regenerate all three files together
and verify their diff before updating this directory.
